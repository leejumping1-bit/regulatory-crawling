# MDCG predecessor discovery

Google Search grounding is disabled even when `GEMINI_API_KEY` is set; no grounding requests or associated grounding fees are incurred. This does not disable the application's separate Gemini summarization feature, which may incur its own fees.

The predecessor adapter uses the European Commission's public search at `https://ec.europa.eu/search/` without an API key. It follows at most four exact-host issuer update pages matching the immediate predecessor and collects at most eight issuer PDF links, respecting robots, size and timeout limits. The PDF identity, revision and component are independently verified before comparison. Search results are not exhaustive and cannot establish that a predecessor does not exist. Appendix discovery is not supported. An independently verified LNE/G-MED external archived copy is currently implemented only for MDCG 2026-4 rev.1; it is labeled external, not an official-site predecessor.

A `revision_history` entry retains the official text exactly. A Korean explanation is included only for a specifically recognized, verified history statement. When a catalogue also exposes an exact predecessor, the record stores page-numbered raw extracted-text differences, not an automated determination of substantive legal change. The existing UI does not display these additional comparison fields for `revision_history` records. Without a verified comparison the history alone does not establish exact before/after text.
